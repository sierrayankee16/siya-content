# siya-content

Werkzeug für SIYA-Media-Carousels (1080×1350).

- `tools/render.py <post.json>` rendert alle Slides als PNG (Playwright/Chromium).
- `tools/beispiel_dunkel.json`, `tools/beispiel_hell.json`: Vorlagen für beide Varianten.
- `posts/`: nur kurzfristig, bis Metricool die Bilder übernommen hat. Danach wird der Ordner wieder geleert.
